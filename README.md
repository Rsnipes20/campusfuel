# CampusFuel — BSAD 281 student prototype

A fictional calorie and macro tracker for university students. Plain HTML, CSS and JavaScript, adapted from https://github.com/dmattie/ai-to-startup-template. No installation, dependencies, build tools or network services.

## Open locally

Keep index.html, styles.css, data.js and app.js together. Open index.html in a browser. Browser-local saving may vary with local-file settings; GitHub Pages provides a normal web origin.

## Project links and editing

Repository: https://github.com/Rsnipes20/campusfuel

GitHub Pages setup and deployment verification are in progress. See the project log for the current status.

To edit in the browser, open this repository, choose Code → Codespaces, and open your existing workspace (or create one if none exists). The desktop VS Code app can also open a local clone. Commit and sync changes after testing. The original instructor instructions are preserved in TEMPLATE_README.md.

## Included behaviour

Search 16 fictional foods; choose meal and servings; add/remove entries; edit the illustrative daily goal; save favourites; switch between seven demo days; review totals; export CSV; reset the sample week; explore an explicitly hypothetical switching-cost illustration.

Local browser storage is device-specific. There are no real accounts, food recommendations, payments or server connections. Reset clears this app's demo edits only. CSV export demonstrates data portability.
